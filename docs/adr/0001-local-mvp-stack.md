# Стек локального MVP

Принято пользователем 12 октября 2026 года. Для однопользовательского приложения на macOS выбираем один Node.js LTS + TypeScript backend с Fastify, обслуживающий React + Vite UI; SQLite через `better-sqlite3` без ORM хранит состояние, файлы — отчёты и логи, HTTP JSON обслуживает действия, SSE — события. Один язык и локальная база с одним владельцем позволяют обойтись без отдельных сервисов, Redis/PostgreSQL, Electron и multi-provider SDK; исполнение обеспечивают Codex CLI, Git worktrees и авторизованные `gh`/`glab`.

Backend живёт независимо от вкладки; pipeline заканчивается созданием PR/MR, CI и merge остаются на hosting. Точные версии фиксируются в lockfile при реализации; совместимость native dependency `better-sqlite3` с выбранной Node.js LTS проверяется на текущем Mac в первом вертикальном срезе. Принятие стека не подтверждает ещё не выполненные интеграционные проверки из технического дизайна.
