# Triage labels

| Роль | Label в GitHub | Значение |
| --- | --- | --- |
| needs-triage | needs-triage | Требуется первичный разбор |
| needs-info | needs-info | Ожидаются уточнения |
| ready-for-agent | ready-for-agent | Готово к выполнению AI-агентом |
| ready-for-human | ready-for-human | Требуется выполнение человеком |
| wontfix | wontfix | Решено не выполнять |

Когда skill указывает роль, используй соответствующий label из таблицы.
