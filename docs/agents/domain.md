# Domain docs

## Layout

Single-context: `CONTEXT.md` в корне и ADRs в `docs/adr/`.

## Правила чтения

Перед исследованием проекта прочитай `CONTEXT.md` и ADRs,
относящиеся к текущей задаче.

Если этих файлов нет, продолжай без замечаний об их отсутствии
и без предложений создать их заранее. Skill `domain-modeling`
создаёт их по мере определения терминов и принятия решений.

При упоминании доменных понятий используй термины из `CONTEXT.md`.
Если нужного понятия нет, проверь принятую лексику проекта;
реальный пробел отметь для `domain-modeling`.

Если предложение противоречит ADR, явно укажи ADR и причину,
по которой решение стоит пересмотреть.
